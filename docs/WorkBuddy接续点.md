# WorkBuddy 接续说明

先读取仓库根目录 `CURRENT_STATUS.md`，再读完整方案、动作验收清单和原画风格执行约束。全部23项问题、60个动作×服装组合、12组双人场景及显示/交互/启动验收仍有效。

## 画风基准

用户明确指定现有咖啡女仆装截图对应的细致 Q 版画风。保留现有原画的脸型、比例、发丝、浅绿配色/高光、红斗篷与裙装结构、衣料和蕾丝细节。角色身份必须是塞西莉亚（浅薄荷绿色长发、绿色眼睛）。以 `docs/原画风格验证/用户指定的原画风格.png` 及三套基准原画为最高优先级。`拒收-改画风候选清单.json` 中的画稿不能作为生成/训练/对照输入。

## 当前可复用的重构工作

- 现行安装包和原有风格资产按 manifest 打包在仓库根目录。
- 现有原画的不同深度、有限透视/光照与脚底锚点已做技术试作；目前只有短原生录像，不是生产完成。
- 录制起始帧锁定、有限水平配准、眼睛定位的代码和以前通过的针对性测试，在 `rebuild/`。这些都是候选实现，尚未合入安装基线。
- 眨眼只能改变眼睛区域；其余原画像素在同一固定姿势下要保持一致。先用原画做有限眼睑编辑，不要重画全身。

## 后续工作顺序

1. 先在咖啡装/经典装/旅行装原画上验证完整循环的2.5D深度与锚点，保留局部原画特征；录屏看正常桌面尺寸。
2. 用原有脸部和眼睛绘制睁眼、半闭、闭眼状态，验收只有眼周像素变化，再验证3–6.5秒不规则眨眼和连续呼吸。
3. 按原 OP 参考制作完整72个生产曝光，含低手摆动、左右转身、背面、回正、斜上举臂；源画面17/18、53/54为合法重复曝光。入场12拍与返回24拍仍需单独完成/验证。
4. 对相邻姿势检查局部连续性、可视边界、实际 GPU 尺度和脚底锚点；先独立GPU预览，再原生桌面录制。录制确认第0帧后再启动动作时钟。
5. 逐项重做其余动作、双人场景、真实鼠标交互、转场、速度/合成、120Hz真实呈现、冷启动、多屏与不同DPI验收。分别记录候选、原生试作、已安装、冷启动状态。

不要把“成功生成”“单元测试通过”“录屏中看见0–23索引”写成画风通过或整体完成。
