# 原画风格执行约束

用户在2026-10-15明确选择第一张现有女仆装桌宠截图的画风，并要求继续沿用之前已经制作好的画风。该要求优先于此前候选的发色量化、头身校准和新原画方案。

问题原因：此前将S3候选自身作为后续主参考，修正发色时又沿用其新比例、较圆的脸、偏柔化的线条和发束，导致画风逐次偏离原稿。2.5D渲染升级并不要求更换角色画风。

制作约束：

1. 保留原稿的脸型、头身比例、眼睛结构和神态，不另做一套人物设计。
2. 保留原稿浅绿色头发及已有的淡黄色高光关系，不以新指定的统一RGB配色重新上色。
3. 保留清晰细线、分束发丝、衣褶、蕾丝、蝴蝶结和原有材质层次，避免把精致线稿柔化成平涂或塑料质感。
4. 三套服装分别使用对应原稿作主参考；官方动漫图仅辅助核对角色身份，不覆盖用户选择的Q版画风。
5. 新增表情优先只改眼睑、嘴角等必要区域；新动作沿用同一角色模型。待机身体无需重复重画。
6. 2.5D通过受限深度、视差、光照和小幅跟随实现；转身与互动仍按原计划制作真实完整姿势。
7. 检查正常桌面尺寸下的实际观感。技术数据、像素数、GPU或原生播放成功都不能替代画风一致性。

本轮已隔离的内容：上一批改画风待机和OP0–29的原画。其技术记录保留为诊断证据，不计为已通过的艺术制作进度。中断的OP30–35生成没有返回结果，迟到结果也不能自动使用。

当前验证使用原安装包7项源素材的逐字节副本，涵盖三套portrait、三套painted及共享原identity_face；没有重新绘制原稿。详见[原画风格锁定与源文件哈希](原画风格锁定与源文件哈希.json)。

当前生成的是原画2.5D渲染试验，尚未宣称完整待机、完整OP或整项重构完成。新眨眼、完整编舞、其余动作和最终安装等要求继续保留。
