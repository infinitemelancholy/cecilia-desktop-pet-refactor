## 仓库内容

- 根目录代码、测试、`manifest.json` 与 `art/runtime/canonical25-v5/` 构成当前安装基线。manifest 的83个资源引用都已打包。
- `art/outfits/`、`references/` 和 `verification/` 留存服装/角色素材记录、OP 参考和旧版基线证据。外部参考视频本体没有放入仓库，参考来源记在 `来源与动画说明.md`。
- `docs/原画风格验证/` 保留用户指定的样式截图、三套原画、哈希、拒收记录和 GPU 对照。`docs/原生试作证据/` 记录本轮使用原画进行的原生短录制。
- `rebuild/` 仅存未安装的中性技术候选、配置和测试；不包含被拒绝的新画稿。

## 在 Windows 上运行现有基线

此包是接入现有 Codex/ChatGPT 桌宠窗口的本地扩展，不是一个独立的 ChatGPT Pets 上传包。需要本机安装的客户端以及原来使用的 Python/Node 运行环境。按 `使用与恢复.md` 操作；**克隆或打开本仓库不会自动安装/替换本机宠物，也不要移动现有已安装目录来试跑。**`runtime/` 中状态、日志和 PID 是本地运行生成物，已由 `.gitignore` 排除。

## 验收规则

技术测试通过、播放器索引出现、绘制次数或 GPU 录像不能代替正常桌面大小的人工画风/动作审核。只有候选素材符合用户指定的原画风格，并经过原生桌面录像和安装/回滚检查，才可标记为安装完成。历史 `verification/` 仅描述现有基线，不代表当前重构已全量通过。
